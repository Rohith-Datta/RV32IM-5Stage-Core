8. Emergency Troubleshooting Matrix

Symptom / Error Probable Root Cause Exact Instant Fix
Core hangs / freezes on first instruction icache_stall is permanently stuck high because valid_bit array was uninitialized. In icache.v, add an active-low reset loop initializing all valid[i] <= 1'b0; on reset_n == 0.
UART outputs weird / garbled symbols Baud rate clock divider mismatch (e.g. 50 MHz divider used instead of 100 MHz). For 100 MHz clock and 115200 baud, set clock divider parameter to exactly 868 (100,000,000 / 115200).
FPU produces NaN or 0 on valid inputs Significand hidden leading bit (1.M) was omitted during normalization. Ensure mantissa is expanded to 24 bits: {1'b1, fraction[22:0]} for normalized numbers.
Negative slack in Vivado after adding FPU FPU combinational path + ALU multiplexer exceeds clock period. Ensure target clock constraint in nexys_a7_100t.xdc is set to 20.0 ns (50 MHz).
